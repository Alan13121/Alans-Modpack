# Mine World / 礦世界

把主世界的八種礦物各丟一個進有水的鍋釜,鍋釜就變成「世界鍋釜」,通往一個全是石頭和礦物的專屬世界。

- **建立**:煤、銅、鐵、金(粗礦或錠都行)、紅石、青金石、鑽石、綠寶石各 1 個,丟進有水的鍋釜(物品會被消耗,重複的種類不吃)。
- **一鍋一世界**:每個世界鍋釜有自己的世界 ID 和種子,數量不限。敲掉鍋釜會掉出帶世界 ID 的鍋釜,重新放下就接回同一個世界。用命名牌可以幫世界鍋釜取名。
- **進入**:站在世界鍋釜裡(或邊緣上)蹲下 4 秒。
- **回來**:出生小房間裡的「回程方塊」(不可破壞)上蹲下 4 秒,回到鍋釜上方(被擋住就找最近的空位)。
- **世界**:全實心石頭(石頭、深板岩、花崗岩、閃長岩、安山岩、凝灰岩),八種礦密度為原版 ×8 且不限高度,高度 -64 ~ 320、上下基岩,無天空、全黑、無自然生成生物。
- 死亡後在主世界重生,礦世界裡床不能用。

## 實作

- 世界在執行時建立(`DynamicLevels`):自己 new `ServerLevel` 放進伺服器的 levels,存檔資料夾是 `dimensions/mineworld/w<N>`,啟動時依 `MineWorldData` 重建。每個世界的種子由 `ServerLevelMixin` 提供。
- 世界生成完全是資料:`scripts/gen_mineworld_data.py` 產生 noise settings(全實心)、biome、placed feature、dimension type 與方塊貼圖。改礦密度改腳本頂端的 `ORE_MULTIPLIER` 後重跑。
- 測試:`./gradlew :mods:mineworld:runClientGameTest`(丟礦、進入、取樣世界、存檔重開、回程、掉落)。
