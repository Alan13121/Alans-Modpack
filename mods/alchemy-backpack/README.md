# 煉金背包 Alchemy Backpack

Minecraft Java **26.3**／Fabric，Java **25**。第一版 `0.1.0`。

## 安裝

1. 為 Minecraft 26.3 安裝 Fabric Loader 0.19.5 或更新的相容版本。
2. 下載 **26.3 專用 Fabric API**（本專案測試使用 0.160.6+26.3）。
3. 把 Fabric API 與 `mods/alchemy-backpack/build/libs/alchemy-backpack-0.1.0.jar` 放入該遊戲實例的 `mods` 資料夾。
4. 使用 Fabric 設定啟動遊戲。多人遊戲的伺服器與所有玩家都需要安裝此模組和 Fabric API。

官方下載：
- https://fabricmc.net/use/installer/
- https://modrinth.com/mod/fabric-api

請使用沒有 `-sources` 字尾的 JAR。開發測試資料位於本專案的 `run/`，與正常遊戲存檔分開。

## 取得背包

創造模式的「工具與實用物品」分類，或使用指令：

```mcfunction
/give @s alchemy_backpack:backpack
```

生存模式工作台配方（皮革 ×5、金錠 ×1、鑽石 ×2、箱子 ×1）：

```text
皮革  金錠  皮革
鑽石  箱子  鑽石
皮革  皮革  皮革
```

目前物品外觀沿用原版束口袋貼圖；介面為自訂深綠色配金色設計。

## 使用

- 主手持背包，按右鍵開啟。
- 指向物品可查看單個與整組 EMC 能量。
- 放進左上轉化格，物品會被消耗，能量立即存入背包。
- Shift＋點擊物品欄可快速轉化整組。
- 首次轉化某種物品後，該背包永久學會此物品。
- 右側列表支援名稱或物品 ID 搜尋、翻頁。
- `1` 兌換一個，`+` 最多兌換一組；依剩餘能量和物品欄空間調整數量。
- 每個背包各自保存能量與學習清單，不與其他背包共享。退出遊戲後保留，交給其他玩家也會保留。
- 能量為 0 的物品不能轉化。背包本身不能轉化。
- 附魔、改名、損壞、裝有內容物或其他非預設資料的物品暫不支援轉化，避免丟失資料或複製內容。
- 開啟時鎖住背包所在格；關閉時退回尚未轉化的物品。

## 能量設定

首次啟動建立 `config/alchemy-backpack-energy.json`。多人遊戲由伺服器設定決定，登入時同步給玩家。

```json
{
  "default": 64,
  "values": {
    "minecraft:dirt": 1,
    "minecraft:iron_ingot": 256,
    "minecraft:diamond": 8192,
    "minecraft:command_block": 0,
    "other_mod:example_item": 128
  }
}
```

- 沒有個別設定的物品（含其他模組）預設 64 EMC。
- 設為 0 代表禁用；單價上限 1,000,000,000。
- 修改後重啟遊戲／伺服器生效。
- **目前為原型價目表，尚未依所有合成、熔煉或第三方模組配方平衡。** 同一物品存入／取出能量守恆，但跨配方轉換可能增加能量；不建議直接用於經濟型公開伺服器。
- 特殊資料物品顯示的是基礎物品單價，同時會標示受保護、不可轉化；不代表可回收附魔／內容物能量。

## 開發與驗證

安裝 JDK 25。專案已設定 Java 25 toolchain。

```sh
./gradlew :mods:alchemy-backpack:build    # 在模組包根目錄執行
./gradlew :mods:alchemy-backpack:runClient
```

Windows 改用 `gradlew.bat`。

`BagDataTest` 驗證存入／兌換、重複學習、餘額不足、非法值、溢位、長整數序列化和背包獨立性。

已完成驗證：`./gradlew build` 成功，7 個單元測試全部通過；Minecraft 26.3 已成功啟動並載入模組。

尚未完成：遊戲內滑鼠操作、合成配方實際合成、多人連線與存檔重開實測。畫面控制工具無法辨識目前的 Java 測試視窗；以下為待執行驗收步驟。

完整遊戲驗收：
1. 取得兩個背包、64 石頭與 1 鑽石。
2. 向第一個背包放入 64 石頭：應為 64 EMC，清單有石頭。
3. 兌換 1 石頭：應為 63 EMC；整組兌換可取回剩餘 63 個。
4. 放入鑽石：應增加 8192 EMC，解鎖鑽石。
5. 搜尋、翻頁，確認能量不足按鈕停用、物品欄滿時不扣能量。
6. 測試 Shift 存入、數字鍵、拖放、關閉背包及背包所在格保護。
7. 第二個背包應仍為 0 EMC，退出並重進後第一個背包資料保留。
8. 改名／附魔物品與裝有物品的界伏盒不得被轉化。

## 程式入口

- `AlchemyMod`：物品、資料組件、選單與網路同步註冊。
- `BagData`：能量與學習清單，不可變且支援持久化。
- `BagMenu`：伺服器交易、物品格鎖定與容量檢查。
- `EnergyValues`：可配置能量表與特殊資料保護。
- `BagScreen`：搜尋、翻頁與兌換介面。
