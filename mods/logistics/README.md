# 物流 Logistics

Minecraft Java 26.3／Fabric，屬於本模組包的一部分。用一個終端機操作基地裡所有的箱子。

## 方塊

| 方塊 | 作用 |
|---|---|
| 倉庫控制器 | 網路核心，每個網路只能有一個；右鍵顯示網路狀態 |
| 物流電纜 | 連接各方塊，也會連到旁邊的箱子／木桶／界伏盒 |
| 倉庫終端機 | 開啟網格介面：顯示全部物品、搜尋（名稱、`@模組`、`#標籤`）、依數量或名稱排序 |
| 合成終端機 | 終端機加 3×3 合成格：材料直接從倉庫取；合成後空掉的格子會自動用倉庫同種材料補滿 |
| 輸入介面 | 接收漏斗／投擲器丟進來的物品存入倉庫；也會把貼著的機器產物（熔爐成品等）收進來 |
| 輸出介面 | 右鍵設定過濾清單，把清單上的物品從倉庫送進貼著的機器或漏斗；清單為空就什麼都不送。每個過濾格可設定「保持庫存」下限 |
| 儲存單元 I～IV | 虛擬倉庫；每升一級，物品種類 ×2、每種數量上限 ×4（I：64 種×1 萬；II：128 種×4 萬；III：256 種×16 萬；IV：512 種×64 萬）。破壞後掉落物保留內容 |

## 網路規則

- 控制器、電纜、終端機、儲存單元互相貼面就連成一個網路（上下左右前後皆可）。
- 貼著任何網路方塊的原版箱子、木桶、界伏盒自動算進倉庫。漏斗、熔爐等不會被使用。
- 存入順序：已有同種物品的箱子／單元 → 箱子空位 → 單元新增種類。

## 終端機操作

- 游標拿著物品點網格：左鍵全部存入、右鍵存入一個。
- 空手點物品：左鍵取一組、右鍵取半組、Shift＋左鍵直接放進背包。
- 在背包欄位 Shift＋點擊：存入倉庫。滾輪捲動網格。

## 效能

針對大倉庫（實測：4200 個木桶、2180 條電纜、約 11 萬組物品、1667 種）做過最佳化：

| 操作 | 優化前 | 優化後 |
|---|---|---|
| 找網路（掃描電纜） | 5–8 ms | 0.0002 ms（快取） |
| 統計全部物品 | 27–40 ms | 0.8 ms |
| 取出／存入一組物品 | 1.4–4 ms | 0.2–0.6 ms |
| 拓撲改變後重建（例如多放一條電纜） | — | 約 5 ms 掃描＋約 40 ms 讀取全部容器（一次性） |

做法：

- **網路快取**：只有網路旁邊的方塊改變（放置、破壞、鄰居更新）或它碰到的區塊載入／卸載時才重新掃描；另外每 60 秒保底重建一次。
- **增量讀取**：每個容器只在它回報有變動（`setChanged`，由 `BlockEntityMixin` 計數）時才重新讀取；另外每次操作順便重讀少數幾個容器當保險，避免其他模組忘記回報。
- **物品索引**：存入和取出只走實際有那種物品的容器，不再掃過整個倉庫。
- **只傳差異**：終端機只把改變的物品傳給客戶端（首次或網路改變時完整傳送，每個封包最多 256 筆），名稱與排序資料在客戶端快取。

自己量測：

```sh
LOGISTICS_BENCH=1 ./gradlew :mods:logistics:runClientGameTest
```

## 農場介面

懸在農田**上方**，管理以自己為中心、**9×9**、往下 **3 層**的範圍（作物那層和耕地都要在裡面；甘蔗、仙人掌、竹子要留一格以上的生長高度）。收成品直接進倉庫，網路要有控制器；沒有控制器就完全不動作。

- 成熟的小麥、胡蘿蔔、馬鈴薯、甜菜根、地獄疣：收成後用掉落的種子補種，掉落沒有種子就從倉庫拿一顆。
- 甘蔗、仙人掌、竹子：只砍底部以上的部分，底部保留讓它繼續長。
- 西瓜、南瓜：只砍旁邊有瓜莖的那顆果實。
- 選單裡的「使用骨粉」開關（預設關）：開了就從倉庫拿骨粉催熟幼苗與瓜莖。
- 升級：紅石縮短間隔，石英增加每次處理的株數（預設 4 株、最多 32 株）。
- 不處理：可可豆、甜莓叢、火炬花、海帶、樹木、動物。
- 只在區塊載入時運作；範圍內未載入的區塊會跳過。
- 配方：輸入介面＋鐵鋤（無序）。

## 自動合成器

倉庫自己動手合成，不需要紅石。右鍵開啟：

- **配方圖樣**：左邊 3×3 是圖樣，拿著物品點格子設定（空手點清除，背包裡 Shift＋點擊放進第一個空格）。右邊預覽會顯示成品。任何工作台配方（有序或無序）都能用。
- **Lookup 的「+」**：在自動合成器畫面開著時，Lookup 配方頁的「+」會直接把該配方設成圖樣；有多種可用材料時（各種木板）選倉庫裡最多的那種。
- **保持庫存**：預設 64。倉庫裡的成品少於這個數字才會合成；在成品格或圖樣上滾動滾輪調整，Shift 一次 16，最大 9999。沒有這個上限它會把材料一直做下去。
- **運作**：每次取出一套材料、合成、把成品和剩餘物（例如空桶）放回倉庫。材料不夠就等。倉庫滿了成品會掉在地上。
- **升級**：紅石縮短間隔；石英增加每次合成的次數（預設 1 次，最多 8 次）。
- 圖樣上的物品必須是**那一種**（不會自動用同類別的替代品）。
- 配方：合成器＋輸入介面＋輸出介面（無序）。

## 輸出介面的庫存下限

過濾格上滾動滾輪可以設定「保持庫存」：介面只會補到目標容器裡有這麼多為止（數量是目標所有格子加總），被機器用掉或被拿走後再自動補回。Shift＋滾輪一次調 16。

- 設為 0（預設，格子上不顯示數字）＝不限制，盡可能塞滿。
- 例：熔爐旁設「煤炭 8」，熔爐燃料格永遠保持 8 個煤炭；上方設「鐵礦 16」，原料格保持 16 個。
- 換掉過濾物品時，下限會重設為 0。

## 儲存單元壓縮

- 四個同級的儲存單元在合成格排成 2×2，合成出高一級的單元，**內容物會全部合併**進去。
- 合併後種類或數量超過新單元上限時，配方不成立（不會弄丟東西）。IV 是最高級。
- 反過來：合成格放**一個** II 級以上的單元，得到一個低一級的單元（帶著全部內容物），另外三個空的低一級單元會回到合成格。
- 解壓縮要求內容物放得進**一個**低一級單元（種類與每種數量都不超過它的上限），否則配方不成立；滿載的單元要先取出一些東西。
- 這些是特殊配方，原版配方書看不到；Lookup 有「儲存單元壓縮」與「儲存單元解壓縮」分頁可查。

## 介面升級

輸入介面與輸出介面右鍵可開啟畫面，有 4 個升級格（每格最多 8 個），只能放紅石與石英：

| 升級 | 效果 | 上限 |
|---|---|---|
| 紅石 | 縮短間隔：預設每 10 刻一次，16 個紅石時每 1 刻一次 | 算到 16 個 |
| 石英 | 每次搬更多：預設 32 個，每個石英 +14，16 個時 256 個 | 算到 16 個 |

拆掉介面時升級會掉出來。

## 合成終端機

- 網格與終端機相同；右側是合成格。游標拿著倉庫物品，右鍵合成格放一個，左鍵放整組。
- Shift＋點擊結果：連續合成，直到倉庫沒有材料或背包滿為止（每次合成後自動補格）。
- 「存回倉庫」按鈕把合成格整個放回倉庫；關閉畫面時合成格剩下的東西也會自動放回倉庫。
- 背包內 Shift＋點擊會把物品存入倉庫（不是塞進合成格）。
- Lookup 配方頁的「+」（Shift＝最大量）會直接從倉庫取材料填進合成格，用不完的會自動退回倉庫。做法是先把需要的材料暫時搬進背包、交給原版放置邏輯、再把剩下的退回，所以背包要有空位。

## 與 Lookup 連動

開著任一終端機時打開 Lookup 配方頁（R／U），每個材料格右下角會顯示倉庫存量：夠是綠色、不夠是紅色，右下角「×N」是用倉庫存量還能合成幾次。有替代材料的格子（各種木板）顯示存量最多的那一種。沒開終端機時不顯示。

## 支援的原版工具方塊

| 方塊 | 輸出介面（送進去） | 輸入介面（收出來） |
|---|---|---|
| 熔爐／高爐／煙燻爐 | 上方送原料、側面送燃料 | 成品與剩下的空桶 |
| 釀造台 | 上方送材料、側面送瓶子與烈焰粉 | 只在釀完時收藥水（見下） |
| 堆肥桶 | 從上方一個一個丟入可堆肥的物品 | 滿了之後收骨粉 |
| 漏斗、投擲器 | 可當作通往倉庫外箱子的橋 | — |

釀造台的收取規則：機器不在釀造中，且裡面的原料已經不能再改變那瓶藥水時才收；水瓶（原料）永遠不收。所以「水瓶→地獄疣→粗製藥水」這種流程，粗製藥水會在地獄疣用完（或不再有反應）時被收回倉庫；若要繼續釀下一階段，請把下一階段的原料一直留在上方介面補給。

## 介面的注意事項

- 介面只搬運「貼在它旁邊、不屬於倉庫的容器」，例如熔爐、漏斗；貼著的箱子會被算進倉庫，不會被當成目標。
- 輸出介面遵守原版的面規則：放在熔爐上方送進原料，放在側面只會送進燃料。
- 輸出介面每 0.5 秒最多送 32 個；輸入介面收貨的速度取決於漏斗（每 8 刻一個）。

## 頻道、能量與傳送

**頻道**有名字、擁有者，並且可以設成公開或私有。同頻道的所有網路會**合併成同一個倉庫**：終端機看得到全部庫存，取放、合成、輸入／輸出介面、自動合成器都跨網路運作（每個網路仍各需要一個控制器）。

- **頻道方塊**：接在網路上任一處，**一個網路只能有一個**（有兩個以上，整個網路會停止運作並提示「同一網路只能有一個頻道方塊」；要把更多地方納入同頻道，各自的網路各放一個）。用 ‹ › 在你能用的頻道間切換（含「未選擇」），輸入名字再選公開／私有按「新增」就開一個新頻道並綁定。擁有者（或管理員）可以改名、改公開／私有、刪除；刪除後所有用到它的方塊、卡片、背包都失效。名字在同一個擁有者底下不能重複，每人最多 32 個。
- **私有頻道**只有擁有者（和管理員）看得到、選得到；公開頻道所有人都能選。
- **頻道卡**：合成取得（空白）。放進頻道方塊的卡槽按「寫入頻道卡」寫入目前的頻道，按「讀取頻道卡」則讓方塊改用卡上的頻道——所以擁有者可以把私有頻道用卡片借給別人。卡片記的是頻道代號，改名不會斷線。
- 舊版的編號頻道（1～9999）會自動變成公開頻道「頻道 N」，已經蓋好的東西不受影響；管理員改名後它就成為一般命名頻道。

**能量池**（EMC，和煉金背包同一種能量）：每個頻道一個池子，容量不限，存在該頻道的頻道方塊裡（拆掉頻道方塊會損失它存的能量）。所有終端機、傳送裝置畫面都用文字顯示剩餘能量。
- **太陽能發電機**：白天且頭上無遮蔽時每秒 1 EMC。
- **煤炭發電機**：放煤炭／木炭／煤炭塊，每秒 4 EMC，一塊煤 800 EMC。沒有可存放的頻道時暫停燃燒。
- **煉金背包**：有裝煉金背包模組時，背包介面右邊多一個頻道卡槽，背包介面中間有 ‹ › 可以直接選頻道（只能選，不能新增），或放入頻道卡（直接選的優先），背包的能量就加入該頻道（背包要在線上玩家的物品欄裡才算）。

**傳送裝置**：接在網路任一處。右鍵開選單，從同頻道的其他傳送裝置選目的地，再選「開啟一次」（傳送一次後自動關閉）、「常開」或「關閉」。開啟時頂上有光柱；站上去（剛踏上才會觸發，不會來回彈）就傳到目的地，每次消耗 10 EMC，能量不夠就不傳。只列出目前已載入的傳送裝置。

**天線與無線終端**：天線接在網路上，範圍預設 10 格，裡面每放一個紅石方塊 +5 格（最多 10 個，共 60 格）。無線終端與一張已寫入的頻道卡合成就綁定該頻道；手持右鍵，在同維度、該頻道任一天線範圍內就能開啟（一般終端機介面）。
